# Data uses: what this site collects or sends

Short answer: **this site collects nothing itself.** No cookies, no analytics, no trackers, no forms that send data to a server. Fonts and scripts are stored on the site itself, so visitors' browsers don't contact Google or any other outside service.

| Data | Where it's stored | Outside service that receives it | Why | How long | Linked to the person? |
|---|---|---|---|---|---|
| Standard web request info (IP address, browser type, page visited) | GitHub's servers | GitHub Pages (hosting) | Needed to deliver the pages; GitHub keeps logs for security | Set by GitHub (see GitHub's privacy statement) | Not by us; GitHub may log IP addresses |
| Messages typed in the Contact or Commission form | Nowhere on the site | None. The form only opens the visitor's own email app with the text filled in; the visitor chooses whether to send it | So people can reach Scott without a server or form service | Only in Scott's and the visitor's email | Yes, once the visitor sends the email |
| Clicks on Instagram / YouTube / Facebook links | n/a | Those companies, once the visitor arrives there | Linking to Scott's pages | Their rules | By those companies |

If a form service (e.g. Formspree) or visitor statistics are ever added, add a row here in the same change.
