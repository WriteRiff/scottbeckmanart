# Data uses: what this site collects or sends

Short answer: the site itself stores nothing on visitors' devices: no cookies, no ad trackers. Fonts and scripts are stored on the site, so browsers don't contact Google. Since 2026-11-21 every page loads Cloudflare Web Analytics, a cookie-free visit counter. Otherwise, the only data collected is what a visitor chooses to type into a form. The site footer says this in one line.

| Data | Where it's stored | Outside service that receives it | Why | How long | Linked to the person? |
|---|---|---|---|---|---|
| Contact form: name, email, message | Formspree (copy in Scott's Formspree account) and Scott's email inbox | **Formspree** (formspree.io, US form service, free plan) | So visitors can message Scott without his email address being public | Formspree keeps submissions as set by its plan (check formspree.io/legal); emails stay in Scott's inbox until he deletes them | Yes (name and email) |
| Commission form: name, email, phone (optional), size, delivery choice, message | Same as above | **Formspree** | Commission inquiries | Same as above | Yes |
| Hidden spam-trap field (`_gotcha`, always empty for people) | Formspree | Formspree | Blocks spam bots | Same | No |
| Standard web request info (IP address, browser type, page visited) | GitHub's servers | **GitHub Pages** (hosting) | Needed to deliver the pages; GitHub keeps logs for security | Set by GitHub | Not by us; GitHub may log IP addresses |
| Visitor's IP address and browser info when a form is sent | Formspree | Formspree | Spam protection | Formspree's policy | Possibly |
| Page views: page address, referring site, browser and device type, country, page-load timing (IP address used by Cloudflare only to process, not stored or shown) | Scott's Cloudflare account (Web Analytics, site "scottbeckmanart.com") | **Cloudflare Web Analytics** (free; JS beacon from static.cloudflareinsights.com, no cookies, no fingerprinting) | Seeing how many people visit and which pages and paintings they look at | Cloudflare keeps Web Analytics data for a limited period (see cloudflare.com/web-analytics) | No |
| Clicks on Instagram / YouTube / Facebook links | n/a | Those companies, once the visitor arrives there | Linking to Scott's pages | Their rules | By those companies |
